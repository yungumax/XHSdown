# 字体

## dingtalk-jinbuti-regular.woff2 —— 钉钉进步体 Regular

- 来源：iconfont 字体库「钉钉进步体」
  （页面 https://www.iconfont.cn/fonts/detail?cnid=clpB5hhpYWUN ；该页描述为「涵盖中、英文 7526 个字符，
  专为标题、美术字等场景而生」）。取的是页面里那份预览字体文件。
- 授权：钉钉进步体**永久免费商用**（页面原文：「开放给所有个人和组织——永久免费商用」），
  著作为钉钉与国内字体团队联合打造的品牌字库。使用前以官方页面的版权说明为准。
- 用法：`src/styles.css` 的 `@font-face` 只声明这一款 Regular，`font-weight: 100 900` 覆盖整个字重区间
  （界面上的粗细由浏览器合成 —— 只声明单一字重时，其它字重的文字会落到回退字体、出现两种字形混排），
  `--font` 令牌把它排在第一位，系统字体只作缺字回退。
- 换字体：把新 woff2 放进这个目录，改 `@font-face` 的 `src` 与 `--font` 令牌即可。
  等宽（`--mono`，变量标记与表格数字用）保持系统等宽：等宽是功能性的，要对齐。
